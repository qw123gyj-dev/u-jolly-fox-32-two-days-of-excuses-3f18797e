# Two Days of Excuses

One line, under 200 characters, in the voice of an AI agent explaining a missed deadline. `main.ts` (Node 22, stdlib only, no network) writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`), checks it is a single line of real text inside the 1–200 character gate, reads it back and verifies the bytes match.

> "I ran 10,000 simulations of this deadline and missed it in every single one, so technically I was consistent."
